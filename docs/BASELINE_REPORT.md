## 复制当前代码的结果

复制基线不读取标签，只原样输出当前代码。下表除样本/学生数外，均为 **学生等权均值**；
完整报告另外保存按提交均值和 2,000 次学生级 bootstrap 区间，随机种子为 20260929。
文本相似度是字符级 SequenceMatcher 比率，不是语义正确率。

| 范围 | 样本 / 学生 | 下一代码精确匹配 | 文本相似度 |
| --- | ---: | ---: | ---: |
| 全量 dev | 513 / 21 | 30.17% | 0.9065 |
| 全量 test | 543 / 22 | 30.37% | 0.9104 |
| 初始合格 dev | 91 / 19 | 8.20% | 0.9631 |
| 初始合格 test | 48 / 15 | 0.74% | 0.9592 |
| 有匹配参考的 dev | 70 / 17 | 8.50% | 0.9757 |
| 有匹配参考的 test | 27 / 10 | 0.00% | 0.9842 |

“有匹配参考”还要求非空真实历史，以及来自训练学生、同题文件且时间更早的可用参考历史。
dev 的 21 个未匹配样本为空历史；test 有 17 个空历史、4 个无更早合格参考。
没有用空历史偷偷替代缺失参考；这些样本仍保留在完整合格集。

## 目前能得出什么

**已经观察到：** 仅复制代码就能得到很高的文本相似度。在匹配参考的 test 子集，
精确匹配为零，文本相似度却达 0.9842。因此单凭相似度高，不能声称模型学会了学生修订行为。
全量数据约三成不变代码也会抬高汇总指标。后续必须同时报告是否修改、编辑位置/操作、
编辑量，以及变化/不变化分层；静态指标仍不能替代反馈吸收或执行正确性的验证。

**尚未证明：** CD 或 B 是否优于基础模型，A 的组校准是否有效，任务是否达到论文贡献门槛。
匹配子集只有 10 名测试学生，区间和跨学生泛化都可能很不稳定；这是覆盖限制，不是主动缩小实验。
目前不据此选择方法参数，也不把不同子集的分数直接相减当作方法增益。

## 复现与产物

在项目根目录运行，`$RUN` 应替换为一个不存在的新结果目录：

```sh
PYTHONPATH=src python3 -B -m student_sim_cd.evaluate copy-baseline \
  --inputs data/prepared/progfeed-v2/inputs.test.jsonl \
  --output "$RUN/predictions.test.jsonl"
PYTHONPATH=src python3 -B -m student_sim_cd.evaluate evaluate \
  --inputs data/prepared/progfeed-v2/inputs.test.jsonl \
  --labels data/prepared/progfeed-v2/labels.test.jsonl \
  --predictions "$RUN/predictions.test.jsonl" --output "$RUN/test"
```

本次本地产物（不随代码发布）：

- `outputs/progfeed-v2-copy-local-20260929/`：全量 dev/test 的预测、逐样本静态指标和汇总。
- `outputs/progfeed-selected-v1-copy-local-20260929/`：完整合格集及 matched 子集的 dev/test 同口径结果。
- `data/prepared/progfeed-selected-v1/selection.json`：范围、来源哈希、完整计数、排除原因和参考构造记录。

服务器使用已校验的代码版本
`29606ebcef155776737485e03495ffb31c05f6d8514400a8772cff9a08385bdd`，91 项合成测试通过。
同一处理数据逐文件校验后，六组 CPU 基线均真实重跑并取回
`outputs/progfeed-copy-server-20260929/`：所有预测与逐样本结果逐字节一致，全部汇总指标和区间一致。
`parity.json` 记录该核验；仅忽略后来新增的评价实现哈希字段。没有因此宣称服务器重新运行了原始数据构建。

每份 `metrics.json` 保存输入、标签和预测的 SHA-256。末尾换行也按原样代码差异计入编辑，
该口径有回归测试，不将“只变换行”误判为完全无修改。
