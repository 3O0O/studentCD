# Student Revision CD：研究与实验概览

更新与文献核验截止：2026-10-03。

这是一份面向公开仓库读者的聚合总结。它记录已完成工作、负结果和待验证方案；不包含学生正文、逐学生结果、模型输出或个人运维记录。详细数值见[聚合结果](RESULTS.md)，机制检查见[失败分析](FAILURE_ANALYSIS.md)，后续讨论见[实验草案](NEXT_EXPERIMENTS.md)。技术入口见[README](../README.md)与[复现说明](REPRODUCING.md)。

## 1. 要预测的是什么

给定题目、学生当前程序、此前同题提交历史及本次实际反馈，预测这个学生下一次提交的完整源文件。

例如，当前代码同时存在循环边界与累加错误，反馈只解释边界问题。学生可能只修改一个比较符号，继续保留另一处错误；也可能完全修好、不作修改或引入新错误。一次生成正确答案不一定忠实模拟了这一步，但故意保留错误也不一定忠实。需要预测的是学生的行为分布。

真实下一提交只是这一分布的一次观测。当前范围是可观测的相邻同名源文件修订，不包括未提交后续代码的学生行为，也没有自动扩展到完整多文件项目或跨题学习过程。

## 2. A 与 B 的假设

### A：先控制结果概率，再比较具体修改

原始 A 设想将候选划为完成、部分改善、停滞、退步等结果组，预测组概率 `q(g | 当前状态, 历史, 反馈)`。不同排序方法共用同一个 q，检验在相同结果概率下，历史对比是否更准确地预测“改哪里、怎样改”。

在组 `g` 内，给候选 `y` 的概率为：

$$
P_A(y)=q(g(y))\frac{\exp S(y)}{\sum_{z\in\mathcal C_{g(y)}}\exp S(z)}.
$$

这只是有限候选池上的分组校准构造，归一化公式本身不是新颖性主张。如果正概率组没有候选，就不能实现该组概率；实现必须明确失败。即使完整分布满足 q，取最高概率的单个代码也不保证输出频率满足 q。

**已完成的 A 只采用文本“改动／不改动”二组**：下一文本完全相同为不改动，否则为改动。它不等于可执行的进步结果、知识掌握或学习收益。完整进步 A 尚未完成。

### B：历史与当前反馈如何共同改变模型支持

对同一个候选计算四个完整代码序列对数概率 `l11、l01、l10、l00`。第一位选择真实／参考历史，第二位选择保留／遮去本次具体反馈；题目、当前代码和基础判题信息始终保留。

$$
D_0=\ell_{10}-\ell_{00},\qquad
D_1=\ell_{11}-\ell_{01},\qquad
\Gamma=D_1-D_0.
$$

统一分数 `S = l11 + αD0 + βΓ` 给出四个固定对照：

| 方法 | α | β | 解释 |
| --- | ---: | ---: | --- |
| base | 0 | 0 | 真实历史与反馈下的基础模型，共享池内排序 |
| history_d0 | 1 | 0 | 额外加入无具体反馈条件下的历史差 |
| CD | 1 | 1 | 等价于 `l11 + (l11 − l01)` |
| B | 0 | 1 | 基础分加历史—反馈交互 |

这里的差分是模型内部条件交互，不能解释为真实学生的反馈因果效应。当前实验是完整代码序列重评分，不是在线逐 token CD。具体字段与参考匹配见[推理协议](INFERENCE.md)。

## 3. 已建成的数据与工程基础

[ProgFeed](https://github.com/umass-ml4ed/progFeed-dataset-public) 静态重建得到 215 名学生、17 个作业、5,355 个有效相邻修订对；训练／开发／测试为 4,299／513／543 对，按学生划分。CSV 的测试行先聚合为提交；真实重复提交保留；缺少下一提交、缺文件及题目错配单独审计。

真实模型实验限定在五个题目与源文件已核验的单文件任务、实际下发非空反馈、非空历史和合法训练参考历史的共同开发子集：**70 条、17 名学生**。这是条件筛选后的队列，不代表全部 ProgFeed 或全部编程学生。数据重建、历史严格过去、输入与标签隔离规则见[数据协议](DATA_PROTOCOL.md)。

目前实现包括：

- 数据重建、来源哈希、缺失审计、按学生划分和上下文完整性检查。
- 单模型候选生成、四条件计分、共享池选择、固定格式提取和单 EOS 协议。
- 静态 A 概率拟合、学生留出交叉验证、候选分布、行为指标与学生配对 bootstrap。
- 独立标准库结果核验、预算记录及完成门禁。核验程序不执行学生代码。

真实模型阶段使用 Qwen2.5-Coder-7B-Instruct。基础评分为完整 canonical 代码加一个 EOS 的 log probability 总和，没有长度归一化。候选真值不进入生成或排序；所有比较保留同一批样本，不因重复、截断或差结果补抽样。

## 5. 主要结果

### 缓存修正：没有可靠 B 优势

主指标为等权学生宏修改位置 F1：先求每位学生的样本平均，再对学生等权平均。它依据文本 diff，不能检验程序语义正确性。下表取每个方法最高分候选：

| 方法 | 学生宏位置 F1 |
| --- | ---: |
| base，共享池排序 | 0.246327 |
| history_d0 | 0.243620 |
| CD | 0.242836 |
| B | 0.242297 |
| 原 greedy | 0.217181 |
| copy | 0.084967 |

B−base 为 **−0.00403026**，描述性学生配对 95% 区间 **[−0.01151713,+0.00084529]**。base 不是 greedy，不能把池内排序收益解释成 B 收益。

### 历史干预：尚未支持真实历史的 B 专属增益

冻结比较为原 `(B−base)` 减历史替换后的 `(B−base)`：

| 替换条件 | 差中之差 | 描述性 95% 区间 |
| --- | ---: | --- |
| 替换真实历史 | −0.00709019 | [−0.01981911,+0.00369412] |
| 替换参考历史 | −0.00182417 | [−0.00837790,+0.00245976] |

两个区间都跨零。任务、时间和长度匹配不等于学生能力、解题阶段或语义相同，不能据此声称替代历史更好，也不能否定所有历史建模方式。

### 候选支持：扩大来源没有解决 B 的问题

均衡池从四条件各取三次随机尝试；11-only 对照只从真实历史与反馈条件取十二次，两池共享原 greedy 与 copy。使用同一评分与选择规则：

| 候选池 | base F1 | B F1 | B−base |
| --- | ---: | ---: | ---: |
| balanced12 | 0.249149 | 0.244645 | −0.004504 |
| 11_only12 | 0.242461 | 0.241842 | −0.000619 |

冻结主交互 `(B−base)_balanced12 − (B−base)_11_only12` 为 **−0.00388513**，区间 **[−0.00904406,+0.00077243]**，没有可靠 B 专属收益证据。

学生修订提示 greedy／pool F1 为 0.214449／0.266512，保守编辑提示为 0.218484／0.235936。它们是可复现提示对照，不能冒称已经复现 KT、SFT 或 Agent。

过量编辑在各方法中持续存在：真实编辑规模学生宏均值 **7.064**，均衡池 base／B 为 **18.615／19.088**；除 copy 外，各方法都修改了全部 70 条，其中 5 条真实未改动也全部被改动。

含 copy 的候选标签上界 F1 为 0.472878／0.453251，生成候选上界为 0.387911／0.368284。因此候选支持不足与选择损失同时存在。上界利用未来标签，只用于诊断，不能作为可部署选择器。没有生成候选精确匹配真实下一文本，也不等于没有语义合理候选。

### 静态 A：q 没超过简单控制，CD 的幅度误差更差

主训练队列为 **737 条、140 名学生：700 改动、37 不改动**。五折按训练学生留出；预声明反馈数值模型为主 q，不按结果改选最优模型。该模型使用反馈规模等数值，不等于理解反馈语义。

| 预声明 q | 学生宏 log loss，越低越好 | Brier，越低越好 |
| --- | ---: | ---: |
| 总体频率 | 0.180375 | 0.041418 |
| 任务频率 | 0.176815 | 0.041139 |
| 当前数值 | 0.180409 | 0.041469 |
| 历史数值 | 0.188855 | 0.041970 |
| 反馈数值，固定主模型 | 0.189559 | 0.042026 |

主 q 减任务频率的 log loss 为 **+0.01274426**，区间 **[+0.00191808,+0.02845323]**，正差表示更差。反馈数值与任务频率使用不同特征，这不是“反馈无用”的实验。五箱 ECE 虽仅 0.001612，但 736／737 概率在同一粗箱；0.5 阈值下全部预测改动，不能把总体准确率或低 ECE 当作个体区分能力。

主排序比较改为**完整概率分布的期望位置 F1**，与前面的最高分候选 F1 不同：

| 主均衡池方法 | 期望位置 F1 | 期望编辑规模 |
| --- | ---: | ---: |
| A+base | 0.246221 | 17.992 |
| A+CD | 0.264536 | 20.066 |

冻结主差 A+CD−A+base 为 **+0.01831534**，区间 **[−0.01053478,+0.05720557]**，17 名学生中 8 正、9 负。位置分数没有稳定额外收益证据；编辑规模 CRPS 差为 **+1.705204**，区间 **[+0.235832,+3.753384]**，说明幅度分布误差更差。

相同 q 使四种 A 的改动概率指标相同，这是代数约束。copy 是不改动组的唯一候选，组内没有排序空间；只给它约 5% 概率，不能解决识别哪些记录不改动。二组 A 也不能单独控制改动后的幅度。

## 6. 如何解释这些负结果

**已观察事实**：当前原型未呈现可靠 B 专属增益或稳定 A/CD 条件收益；修改幅度过大；低成本 q 未超过频率控制。描述性学生配对区间使用 2,000 次 bootstrap、固定 seed 20260929，不是确认性显著性检验。

**待验证解释**：基础模型可能偏向专家式修复，完整代码表示和序列长度可能影响评分；反馈数值特征可能太弱，少数不改动记录的估计可能不稳定；参考历史匹配可能没有控制能力与阶段。现有数据没有证明这些解释的因果机制，不能据它们直接宣布某个模块有罪或更换权重追分。

**验证边界**：新学生与候选正文在运行环境原地核验，受限回传仅含无代码数值和声明哈希；本地数值复算不等于独立重拟合 q 或重新计算模型 likelihood。发布的聚合总结不等于发布了全部复核材料。

所有 70／17 结果都是已见开发集描述性证据。原 27 条匹配测试集此前已有 copy 统计和 tokenizer 静态接触，不能称全盲测试。尚未验收学生代码安全执行、判题重放、完整进步 A、语义反馈吸收、跨模型／跨数据验证、真实学习收益及论文创新。

## 7. 文献诊断与下一步

同类工作说明，下一阶段应增加学习真实修订的强基线，不能仅与提示方法比较：

| 一手工作 | 机制与本项目的关系 | 待注意的差别 |
| --- | --- | --- |
| [CoderAgent](https://arxiv.org/abs/2505.20642) | 学生记忆与分步修改规划；提示我们直接建模修订行为 | 意图／位置判别与当前文本 diff F1 不等价 |
| [ParaStudent v3](https://arxiv.org/abs/2507.12674v3) | 从真实修订与反馈学习学生模拟，并评价功能、风格、语义和反馈采纳 | 不把论文数据或结果当作本项目已取得、已复现 |
| [Conversational Serialization](https://educationaldatamining.org/edm2026/proceedings/2026.EDM.short-papers.181/index.html) | 代码与判题反馈交替形成轨迹，采用 SFT 和偏好优化 | 依赖可执行评价；其数据筛选与本队列不同 |
| [INSIDE](https://arxiv.org/abs/2608.10492) | 已研究联合建模隐含推理与学生行动 | “先推理再修订”已有近邻，推理不等于观测到的心理过程 |

这些文献提供机制对照，不是本项目的实验结果。下一计划仍待冻结与实施：

1. **训练集审查与 q 泛化**：审查全部 37 条不改动的来源、定义和任务分布；在相同任务先验下，比较历史残差和可核查反馈内容特征。保持学生留出，增加时间前推评估；稀有类别加权须单独核对原概率校准，不能以变更先验代替预测改善。
2. **学习真实下一修订**：建立同骨干 code-only SFT、反馈条件 SFT 与训练检索对照；保留局部修改、停滞和回归。比较完整代码与可确定性应用的补丁表示，评价还原后的完整程序，记录 token 与实际成本。
3. **分开生成与排序**：固定共享候选比较基础分、CD、B 和训练排序器；另比较新生成器的支持。统一长度／幅度控制，检验历史是否在共同 q 和相近修改幅度下仍提供个体信息。
4. **恢复完整进步 A**：先验收隔离、禁网、资源限制与判题重放，再冻结测试状态变化组；明确编译失败、缺测和混合变化，不把未知结果当失败。
5. **冻结独立验证**：保留概率 proper scores、位置／操作指标和幅度 CRPS，增加经盲核的反馈采纳及可执行状态变化；在新冻结的独立数据上验证。位置 F1、CodeBLEU、总体分布距离与功能指标各有不同范围，不能互相代替。

拟检验的科学主张是：**控制结果与编辑规模后，真实学生历史是否仍改善具体修订预测；当前反馈是否改变这种条件行为信息。** SFT、补丁、分组归一化与对比公式本身都不构成新的贡献。若收益被简单幅度控制或强训练基线解释，就应停止扩大当前评分公式；这不要求停止探索尚未被检验的修订机制。

## 8. 发布与复现范围

仓库提供研究代码、合成测试、冻结协议、公开技术文档和聚合结论。数据、模型权重、学生正文、逐样本输出、缓存、虚拟环境、凭据和个人运行记录不随仓库发布。资产缺失或哈希不符须明确停止，不能把新生成冒充历史复现。

代码许可证尚未选定；ProgFeed 与模型遵守各自上游许可。完整操作边界、可用检查和资产准备见[复现说明](REPRODUCING.md)。
