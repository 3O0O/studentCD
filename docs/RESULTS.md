# 聚合实验结果与复核边界

截至 2026-10-03，冻结实验没有呈现可靠的 B 专属增益；静态二组 A 的固定 q 未超过任务频率控制，A+CD 的编辑规模误差更差。这限制当前原型的主张，不证明所有历史、反馈或完整进步 A 无效。

完整聚合标量、已存区间、控制方法、q 分箱及来源 SHA 见 [aggregate-results.v1.json](../reports/aggregate-results.v1.json)。本页不含个体记录或学生程序。研究问题见 [研究摘要](RESEARCH_SUMMARY.md)，资产与操作前提见 [复现说明](REPRODUCING.md)。

## 阅读口径

- 各模型阶段反复使用相同 **70 条／17 名学生 dev**，不是独立研究样本；65 条真实文本改动、5 条未改动，没有补采样。
- 学生宏指标先求学生内样本均值，再对学生等权；机器文件另存提交均值。两种平均不能混用。
- 原冻结 95% 区间采用 **2,000 次学生 bootstrap，seed 20260929**；比较时成对重抽学生。它们是已见开发数据的描述性区间，没有多重比较调整，不确认泛化、因果或新颖性。
- **argmax F1** 评价最高分代码；**期望 F1** 用完整候选概率加权候选 F1，不能把期望收益当作最终输出收益。
- 位置／操作 F1 和规模依据文本 diff，不验证语义正确性、知识或学习。F1 越高越好；规模绝对误差、CRPS、Wasserstein 越低越好。
