# Student Revision CD

预测学生收到反馈后的下一次代码提交，探索进步结果校准（A）与历史—反馈对比评分（B）。目标是忠实模拟局部修订、停滞和回归，而不是生成最优解。

**当前结论：工程与描述性实验已经完成，但尚无稳定 A/CD 或 B 收益证据。** 目前实现主要是共享候选池上的完整代码序列重评分；不是在线逐 token CD，也不是已验证的学生学习或教学干预模型。

## 快速检查

从仓库根目录运行。基础模块没有第三方运行时依赖，要求 Python 3.9+：

```sh
python3 -m venv .venv
PYTHONPATH=src .venv/bin/python -B -m unittest discover -s tests -t . -v
```

测试使用合成文本和模拟 backend，不读取真实学生数据或下载模型。未安装可选模型依赖时，相关检查会明确跳过；安装后的小型随机模型检查只在 CPU 内存中构造模型。跳过、合成测试通过、真实模型实验完成是不同证据，不能互相替代。

真实模型推理需要另外准备 PyTorch、Transformers、Safetensors 与本地模型文件。可选依赖版本定义在 [pyproject.toml](pyproject.toml) 的 `inference` extra 中；在适用许可与运行资源允许的环境里可安装：

```sh
.venv/bin/python -m pip install -e '.[inference]'
```

安装依赖不会准备数据或模型。推理读取既有本地模型，禁用远程自定义模型代码；历史整轮实验的资产、模型版本和配置不能由随机模型测试替代。具体命令与边界见[复现说明](docs/REPRODUCING.md)。

## 项目内容

```text
src/student_sim_cd/   数据重建、候选生成、序列评分、概率控制与静态评价
tests/               合成夹具与可选小型 CPU 模型检查
configs/             已冻结的实验协议和范围定义
docs/                公开研究概览与技术协议
scripts/             工作流及独立结果核验入口
```

`data/`、`models/`、`outputs/`、缓存、虚拟环境、凭据与个人运维记录不属于发布内容。冻结配置可能绑定历史运行资产，保留它们是为了记录当时实际协议，不表示可以在任意机器直接启动整轮实验。这个仓库不包含完整实验结果包或学生代码副本。

## 数据与安全边界

- 数据来源为 [ProgFeed 官方仓库](https://github.com/umass-ml4ed/progFeed-dataset-public)。上游数据标为 CC BY 4.0；获取及使用须遵守上游归属和引用要求。本项目没有重新发布教育数据。
- CSV 的测试／函数行不等于提交；先重建相邻提交，再按学生划分。未来代码、未来判题结果与未来反馈不进入推理输入或参考历史。
- 真实重复提交是有效“不改动”记录；没有下一次提交属于未观测，不能标为“不改动”或“已学会”。
- 学生提交及第三方判题程序均作为不可信代码处理。隔离、禁网、资源限制和重放一致性尚未验收，当前流程不执行它们。
- 当前修改位置和文本改动指标不代表程序正确性、知识掌握、个性化因果效应或学习收益。
